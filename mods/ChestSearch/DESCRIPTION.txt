Search nearby chests from one window. Ctrl+F opens your inventory and a search bar with normal item-slot visuals. Type part of an item name to filter separate stacks, then drag a stack onto an empty inventory slot or a matching stack. Hover to see its source chest; use the page buttons for more results.

Default range is 20 metres, adjustable from 5 to 40 in F7. Searches loaded accessible storage containers, including chest inventories and carts; skips wards/private chests you cannot use, busy containers, creature bags, tombstones and recyclers. Up to 64 nearby containers and 512 matching stacks, with 24 slots per page. All typed words must appear in the item's localized name.

Only real chest items are moved. A drag is a visual preview until it lands on your inventory; cancelling, closing, or dropping elsewhere does nothing. Normal chest-owner permission is requested before reloading the source and checking that the selected stack is unchanged. Different occupied slots are rejected; compatible partially full stacks take only what fits. Moving out of range, stale results, denied access and timeouts cancel the transfer.

Native Linux and Windows, no other mod dependency and no custom chest save data. Install on the player using the window; native chest RPCs work with an ordinary host. Ctrl+F and Escape close the search. Mouse drag and keyboard search are supported; controller/touch search are not yet implemented. F6 removes the window and preview without moving items. Compiled and checked against local native assemblies; layout, drag behavior, live ownership transfer, other UI mods and multiplayer still need in-game playtests.
